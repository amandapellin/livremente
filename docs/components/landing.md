# `src/components/landing` — landing page

Componentes da página inicial (`/`).

- **`hero/` → `Hero`** — seção de destaque: título, subtítulo e dois CTAs
  ("Começar a Ler" → `/catalogo`, "Acessar Conta" → `/login`), sobre a imagem de
  fundo do design (`heroBackground`, ver `docs/theme.md`).
- **`feature-card/` → `FeatureCard`** — card de destaque de um recurso (ícone +
  título + texto); a landing usa três (acervo, leitura ativa, sincronização).
